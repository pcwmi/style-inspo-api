Design Rationale & Interactive Behavior

Progressive Disclosure Strategy

  • Threshold: Sub-filters only appear when a category has >12 items
  • No preview indicators: Users don't need to know which categories have sub-filters - they just appear when relevant
  • Entry-level users: See clean, simple category tabs only - no cognitive overhead
  • Power users: Get additional filtering tools when they need them
  • Reset on switch: Sub-filter selection resets to "All" when switching main categories
  • Hide empty: Sub-categories with 0 items are hidden (not greyed out)

Visual Hierarchy

  • Main categories: Bold, prominent pills with strong black active state
  • Sub-categories: Lighter, outline-style chips in secondary position
  • Color coding: Terracotta (#C4613A) reserved for active sub-filter state
  • Background layers: White for main tabs, subtle sand (#FAFAF9) for sub-filter row

Interaction Patterns (Try It!)

  • Click any main category tab to switch - sub-filters appear/disappear based on item count
  • Click sub-category chips to refine - active state shows terracotta background
  • Horizontal scrolling: Both rows scroll independently on mobile
  • Smooth transitions: Sub-filter row slides in/out with CSS transitions

Mobile-First Considerations

  • Touch targets: 44px minimum height for all tappable elements
  • Scroll behavior: Native momentum scrolling on iOS/Android
  • No overlays: Sub-filters push content down (no z-index issues)
  • Performance: CSS transitions only (no JavaScript animation)
