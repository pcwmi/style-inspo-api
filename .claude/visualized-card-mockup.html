Component Reusability

VisualizedOutfitCard Props

{
  outfit: OutfitData
  visualizationUrl?: string
  showVisualizeButton?: boolean
  allowSave?: boolean
  compact?: boolean  // for homepage grid
}

Usage Locations

  • • Reveal page: showVisualizeButton=true, allowSave=true
  • • Saved page: showVisualizeButton=true (if not visualized), allowSave=false
  • • Homepage: compact=true, showVisualizeButton=false

States

  • • Not visualized: Show item collage + "Visualize" button
  • • Generating: Show loading state with progress
  • • Visualized: Show visualization hero + item row

Descriptor Modal (Required)

No skip button - descriptor required to visualize

Recommendation

✅ Option B: Stacked Layout

  • • Visualization as hero image (maximum impact)
  • • Items in horizontal scrollable row (scales to 5+)

  • • Works on all pages (reveal, saved, homepage)
  • • Mobile-first (vertical scroll natural)
