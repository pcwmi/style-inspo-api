Complete User Flow

1

User saves outfit

Clicks heart icon on outfit card

2

"What do you love?" modal

Select feedback checkboxes, submit

3

Outfit card shows "Visualize" button

Only appears after save (cost gate)

4

User clicks "Visualize on Model"

If no descriptor: show setup modal first

5

30-40s generation with progress

User can browse other outfits meanwhile

6

Side-by-side result displayed

Collage vs visualization, tap to expand

Design Rationale

✓

Progressive commitment

Save first = demonstrated interest, reduces wasted $0.08 generations

✓

Preserves feedback loop

"What do you love?" modal stays focused, no competing CTAs

✓

Transparent wait time

Progress bar + steps reduces perceived wait by ~20%

✓

Side-by-side comparison

Sets expectations: AI interpretation, not photo-realistic

✓

Just-in-time descriptor

Only ask for model details when needed, reduces onboarding friction
